# 서스데반의 AI 판독기

Python 3.11 이상과 Streamlit으로 실행하는 문장 개선 웹 애플리케이션입니다. **현재 앱은 OpenAI로 문장을 개선하고 원문 의미를 검토하며, GPTZero 구독이나 API 키는 필요하지 않습니다.** 원문과 최종 본문, 수정 후보와 채택·거절 이력을 함께 확인할 수 있습니다.

사이트 이름과 관계없이 **AI 탐지 점수는 측정하지 않습니다.** 점수 감소, 인간 작성 판정 또는 탐지 회피를 보장하지 않습니다. 의미 보존 평가는 탐지 점수와 별개인 모델의 자동 판단이며 사실과 의미를 완전히 보증하지 않습니다. 최종 문장은 사용자가 확인해야 합니다.

텍스트 입력·PDF 본문 가져오기·예시 글·진행 상태·수정 승인·문서 다운로드를 한 화면에서 사용할 수 있습니다. [DEPLOYMENT.md](DEPLOYMENT.md)에서 Streamlit Community Cloud 또는 Docker/Render 배포 방법을 확인하세요. 개발 환경의 게시와 웹사이트 호스팅은 별개의 작업입니다.

## 구조와 처리 흐름

```text
app.py                   한국어 Streamlit UI, 본문 비교·승인·다운로드
textlab/
  models.py              설정·후보·전체 실행 이력
  editor.py              문장 개선 전용 후보 평가·채택·승인·중지
  guards.py              수치·인용·참고문헌·보호 용어 검사, 문장 통계
  providers.py           OpenAI 문장 개선·의미 검토와 Mock 구현
  transport.py           HTTP 재시도·호출 제한·비용 예약·토큰 집계
  jobs.py                세션별 백그라운드 실행과 승인 큐
  site.py                반응형 스타일·홈 화면·이용 안내
  web_runtime.py         서버 비밀값·선택적 비밀번호·호스팅 보관 정책
  storage.py             실행별 JSON 감사 기록의 원자적 저장
  exports.py             한글 PDF·DOCX·JSON 생성
  pdf_import.py          업로드한 PDF의 본문 추출과 입력 한도 검증
  assets/                한글 PDF 폰트·OFL 라이선스·출처
tests/                   편집·API 계약·UI·내보내기 테스트
Dockerfile               호스팅용 컨테이너 정의
render.yaml              Render 배포 설정 (자동 배포 꺼짐)
DEPLOYMENT.md            계정 연결 후 웹사이트 공개 절차
```

입력 → 개선 후보 생성 → 원문 기준 의미 검토와 보호 검사 → 필요 시 사용자 승인 → 채택 또는 이전 본문 유지 순서입니다. 후보 전체와 채택·거절 이유를 기록합니다. 생성과 의미 검토는 별도 모델 요청이며 의미 검토는 누적 수정본이 아닌 **최초 원문**을 기준으로 합니다. 탐지 서비스에는 요청하지 않습니다.

기본값은 **개선 1회, 회차당 후보 3개**입니다. UI에서 개선 회차(1~5), 회차당 후보 수(1~5), 의미 보존 기준, 중요 수정 승인 여부와 변경 폭 기준, 보호 용어, 호출·예상 비용 한도, PDF/DOCX 출력 형식을 조정할 수 있습니다. 목표 탐지 점수나 점수 감소에 따른 조기 종료 설정은 사용하지 않습니다.

기존 탐지 엔진과 자료형은 이전 기록·테스트 호환을 위해 저장소에 남아 있지만 현재 웹 앱의 문장 개선 경로에서 사용하지 않습니다.

## PDF 본문 가져오기

입력창 위의 **PDF에서 본문 가져오기**에서 PDF를 선택하면 페이지 순서대로 텍스트를 추출해 **원본 텍스트** 입력창에 채웁니다. 업로드가 성공하면 기존 입력을 교체하며 추출한 본문은 직접 수정한 뒤 **시작**을 눌러 개선할 수 있습니다. 설정 변경이나 재실행으로 편집 내용이 덮어써지지 않습니다. 같은 파일을 다시 가져오려면 업로드를 지우고 다시 선택하세요. 업로드를 지워도 입력창의 본문은 유지됩니다.

파일은 최대 **20MB**, 추출한 본문은 최대 **20,000자**입니다. 암호화·손상 PDF, 텍스트 없는 PDF, 한도를 초과하는 PDF는 오류를 안내하고 기존 입력을 유지합니다. 긴 본문을 임의로 잘라 넣지 않습니다. 스캔 이미지의 OCR은 지원하지 않으며 PDF의 표·다단 편집 등 복잡한 배치는 추출 후 확인이 필요합니다. PDF 추출 자체에는 외부 API를 사용하지 않고 업로드 파일을 별도로 디스크에 저장하지 않습니다. **시작** 이후의 본문 기록과 외부 API 전송은 아래 동작을 따릅니다.

## 로컬 설치 및 실행

macOS / Linux:

```bash
cd /path/to/123
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m streamlit run app.py
```

Windows PowerShell:

```powershell
cd C:\path\to\123
py -3.11 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m streamlit run app.py
```

테스트 도구가 필요하지 않다면 `requirements.txt`만 설치해도 실행할 수 있습니다. 설치된 Streamlit이 표시하는 로컬 주소를 브라우저에서 엽니다. 기본 모드는 **테스트용 Mock**이며 키나 네트워크 없이 문장 개선 UI·승인·다운로드 흐름을 체험할 수 있습니다. Mock은 공백·줄바꿈 변경 예시와 공백 제외 동일성 검사만 수행하며 실제 OpenAI 개선이나 의미 모델 평가가 아닙니다. 가상의 탐지 숫자도 만들지 않습니다.

## 실제 API 설정

`.env.example`을 `.env`로 복사하고 본인의 OpenAI API 키를 **로컬 파일 또는 환경변수**에 설정하세요. `.env`는 Git에서 제외합니다. 호스팅에서는 서비스의 비밀값 입력 기능을 사용하고 채팅에 키를 보내지 마세요.

| 변수 | 용도 |
| --- | --- |
| `LLM_API_KEY` | OpenAI API 키: 문장 개선 및 의미 검토에 필요 |
| `LLM_MODEL` | JSON 응답과 `max_completion_tokens`를 지원하는 Chat Completions 모델. 기본 `gpt-4o-mini` |
| `PDF_FONT_PATH` | 선택 사항: 대체 한글 TrueType 글꼴 절대 경로 |
| `TEXTLAB_HOSTED` | 웹 호스팅에서 `1`. 기본 `0` |
| `TEXTLAB_SAVE_HISTORY` | 서버에 원문·이력 JSON 저장 여부: `1`/`0`. 기본 로컬 `1`, 호스팅 `0` |
| `TEXTLAB_MAX_CONCURRENT_RUNS` | 한 서버 프로세스의 동시 작업 수: 1~8, 기본 2 |
| `APP_ACCESS_PASSWORD` | 선택적 사이트 비밀번호. 호스팅의 실제 API 모드에는 필수 |

일반 로컬 환경에서는 `OPENAI_API_KEY`도 대체 입력으로 지원합니다. 기존의 비어 있지 않은 주입 환경변수는 `.env`나 Streamlit Secrets로 덮어쓰지 않습니다. 빈 API 키 환경값은 Secrets의 정상값으로 채울 수 있습니다.

UI에서 **실제 API**를 선택하고 원문과 후보를 OpenAI에 전송하는 데 동의한 뒤 실행하세요. 키가 없거나 권한·요청·응답 검증에 실패하면 설정 오류 또는 안전한 오류 메시지를 표시하며 Mock으로 전환하지 않습니다. OpenAI API 사용 권한과 잔액이 필요합니다. ChatGPT 웹 구독과 API 과금은 별개입니다.

Streamlit Community Cloud에서는 같은 이름을 앱의 Secrets에 **최상위 TOML 항목**으로 설정할 수 있습니다. 저장 후 앱을 재시작하세요. `TEXTLAB_HOSTED=1`인 서버의 실제 API 모드에는 `APP_ACCESS_PASSWORD`가 필요하며 비밀번호가 설정되면 본문에 접근하기 전에 로그인 화면이 표시됩니다. 공개 Mock 체험에는 키와 비밀번호가 필요 없습니다. 로그인은 공유 사이트 비밀번호 방식이며 사용자별 계정·청구 관리 기능은 아닙니다.

실제 개선과 의미 검토는 [OpenAI Chat Completions](https://platform.openai.com/docs/api-reference/chat/create)의 공식 HTTPS API를 사용합니다. 의미 보존 점수는 원문과 후보의 의미가 유지되는지에 대한 모델의 판단입니다. AI 탐지 점수, 저자 판정 확률 또는 사실 보증으로 해석하면 안 됩니다.

## 의미·사실 보존과 사용자 승인

수치(부호·소수 포함), 따옴표 인용, URL, 대괄호 인용, 대문자 약어, 참고문헌 꼬리 부분과 지정한 보호 용어의 변경을 보수적으로 차단합니다. 모든 고유명사를 규칙만으로 식별할 수 없으므로 중요한 이름·전문 용어는 UI 보호 목록에 한 줄씩 넣으세요. 모델에도 고유명사·전문성·문체·논리 구조를 유지하고 근거 없는 내용을 추가하지 않도록 지시합니다. 자동 검사에는 한계가 있으며 숫자의 문맥·귀속이나 미묘한 의미 변경은 사용자가 확인해야 합니다.

중요 수정은 모델이 표시하거나 설정한 문자 변경 비율을 초과한 후보입니다. 보호 검사와 의미 보존 기준을 통과한 후보에 대해 필요한 승인을 받습니다. 거절하면 다른 유효 후보를 검토하고 모두 거절되면 이전 본문을 유지합니다. 승인으로 보호 검사나 의미 기준을 우회할 수 없습니다. 중지하면 진행 중 비동기 요청을 취소하고 이미 채택한 본문을 유지합니다. OpenAI에서 이미 처리한 요청은 취소 후에도 청구될 수 있습니다.

## 사용량, 비용, 오류 처리

기본 한도는 API 요청 200회와 **예약 예상 비용** 5 USD입니다. 후보 생성 1회와 후보별 의미 검토 1회가 각각 요청에 포함됩니다. 기본 1회·후보 3개는 모든 후보를 의미 검토하는 경우 **생성 1 + 의미 검토 3 = 4요청**이며 재시도는 별도입니다. 보호 검사에서 거절된 후보나 유효 후보를 채택한 뒤의 남은 후보는 의미 검토를 생략합니다. 탐지 호출이나 탐지 비용은 없습니다. Mock은 실제 API 호출량과 비용을 소비하지 않습니다.

요청 직전에 UI에 입력한 보수적인 요청당 금액을 예약합니다. 기본 LLM 추정액 0.02 USD는 **현재 서비스 가격표가 아닙니다**. 모델 요금·입력 길이·토큰 상한에 맞춰 설정하세요. 토큰 사용량은 응답에 제공된 집계를 별도로 기록합니다. 예약액은 실제 청구액을 강제 제한하지 못하므로 OpenAI 계정의 지출 한도도 설정하세요. 한도에 도달하면 새 요청을 중단하고 이미 채택한 결과를 유지합니다.

HTTP 429·5xx 및 일시적인 연결 오류만 최대 3회 시도합니다. 지수 지연과 제한된 `Retry-After`를 사용합니다. 인증 오류·잘못된 JSON·범위 밖 의미 평가·잘린 모델 응답은 성공으로 취급하지 않습니다. TLS 검증과 환경의 프록시·CA 설정을 유지합니다. 화면·이력에는 키나 외부 오류 응답 본문을 저장하지 않습니다.

## 기록과 다운로드

로컬 기본 설정에서는 현재 작업 디렉터리의 `.runs/<실행 ID>.json`에 원문·설정·모든 후보·의미 평가·채택/거절·중지 이유를 자동 저장합니다. 각 업데이트는 원자적으로 교체됩니다. **입력 전문이 들어 있는 평문 로컬 파일**이므로 필요가 없어지면 `.runs/`를 삭제하세요. 호스팅 기본 설정(`TEXTLAB_HOSTED=1`, `TEXTLAB_SAVE_HISTORY=0`)은 서버 파일 저장을 끄고 세션 내 결과와 다운로드로 이력을 제공합니다. 기존 기록을 자동 삭제하지는 않습니다. `TEXTLAB_SAVE_HISTORY=1`로 호스팅 파일 저장을 켤 수 있습니다. 실제 API 모드에서는 원문과 후보가 OpenAI에도 전송됩니다. 브라우저를 닫아도 이미 시작한 작업은 프로세스가 살아 있는 동안 진행될 수 있으므로 끝내려면 중지를 누르세요. 서버 재시작 시 실행 중 작업과 승인 대기는 복원하지 않습니다.

완료 또는 중지 후 PDF·DOCX와 JSON 이력을 내려받습니다. 문서에는 원문과 최종 본문, 변경 이력 및 별도의 의미 보존 평가를 담으며 탐지 점수를 표시하지 않습니다. PDF에는 저장소에 포함된 NanumGothic 글꼴을 임베드해 한글을 표시합니다. 글꼴의 OFL 라이선스와 출처는 `textlab/assets/`에 있습니다. DOCX는 편집 가능한 문서입니다. 운영체제에 NanumGothic이 없으면 워드 프로그램이 사용 가능한 한글 글꼴로 대체할 수 있습니다.

## 검증

```bash
python -m pytest -q
python -m pip check
```

테스트는 원문 기준 의미 검토, 보호 조건, 중요 수정 승인/거절, 취소, 호출·비용 한도, 재시도별 예산, API 응답 계약, Streamlit 상호작용, PDF 업로드와 한글 PDF·DOCX·JSON 이력을 검증합니다. 기존 탐지 경로의 호환 테스트도 별도로 유지합니다. API 계약 테스트는 네트워크를 Mock으로 대체하며 실제 OpenAI 연결 성공을 뜻하지 않습니다.

클라우드 온보딩에서는 Python 3.12를 사용합니다. 실제 OpenAI 연결은 배포된 앱의 API 키·계정 권한·네트워크 설정에 따라 확인해야 합니다. 개발 환경의 키는 GitHub push나 외부 호스팅으로 자동 전달되지 않습니다.
