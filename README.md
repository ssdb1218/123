# 서스데반의 AI 판독기

Python 3.11 이상과 Streamlit으로 실행하는 웹 애플리케이션입니다. 원문을 분석하고 가독성 개선 후보를 생성한 뒤, 같은 판독기의 관측 점수와 원문 의미 보존 평가를 함께 비교합니다. 점수가 낮아져도 실제 인간 작성 여부, 탐지 회피, 0% 또는 목표 달성을 보장하지 않습니다.

인터넷에 올릴 웹사이트용 반응형 화면과 배포 설정을 제공합니다. 텍스트 입력·예시 글·실시간 결과·수정 승인·문서 다운로드를 한 화면에서 사용할 수 있습니다. **현재는 배포 준비 상태이며 공개 접속 주소는 생성하지 않았습니다.** [DEPLOYMENT.md](DEPLOYMENT.md)에서 Streamlit Community Cloud 또는 Docker/Render 배포 방법을 확인하세요. 환경 게시와 웹사이트 호스팅은 별개의 작업입니다.

## 구조와 처리 흐름

```text
app.py                   한국어 Streamlit UI, 비교·그래프·승인·다운로드
textlab/
  models.py              설정·점수·후보·전체 실행 이력
  engine.py              비동기 후보 평가·채택·복원·조기 종료·중지
  guards.py              수치·인용·참고문헌·보호 용어 검사, 문장 통계
  providers.py           Detector/Rewriter 인터페이스, GPTZero/OpenAI/Mock
  transport.py           HTTP 재시도·호출 제한·비용 예약·토큰 집계
  jobs.py                세션별 백그라운드 실행과 승인 큐
  site.py                반응형 스타일·홈 화면·이용 안내
  web_runtime.py         서버 비밀값·선택적 비밀번호·호스팅 보관 정책
  storage.py             실행별 JSON 감사 기록의 원자적 저장
  exports.py             한글 PDF·DOCX·JSON 생성
  pdf_import.py          업로드한 PDF의 본문 추출과 입력 한도 검증
  assets/                한글 PDF 폰트·OFL 라이선스·출처
tests/                   엔진·API 계약·UI·내보내기 테스트
Dockerfile               호스팅용 컨테이너 정의
render.yaml              Render 배포 설정 (자동 배포 꺼짐)
DEPLOYMENT.md            계정 연결 후 웹사이트 공개 절차
```

입력 → 최초 판독 → 반복 후보 생성 → 원문 기준 의미 검증과 보호 검사 → 같은 판독기로 재측정 → 더 낮은 점수의 유효 후보 선택 → 필요 시 사용자 승인 → 채택 또는 이전 버전 유지 순서입니다. 반복마다 후보 전체와 거절 이유를 저장합니다. 생성과 의미 검토는 별도 모델 요청이며, 의미 검토는 누적 수정본 대신 **최초 원문**을 기준으로 합니다.

기본값은 목표 **5% 이하**, 최대 **20회**, 반복당 **3개 후보**, **3회 연속 미개선 시 종료**입니다. 중요 수정은 기본적으로 사용자 승인을 기다립니다. UI에서 목표, 반복 횟수(1~20), 후보 수(1~5), 조기 종료 기준, 의미 보존 기준, 승인 여부, 변경 폭 기준, 보호 용어, 호출·예상 비용 한도, PDF/DOCX 출력 형식을 조정할 수 있습니다.

## PDF 본문 가져오기

입력창 위의 **PDF에서 본문 가져오기**에서 PDF를 선택하면 페이지 순서대로 텍스트를 추출해 **원본 텍스트** 입력창에 채웁니다. 업로드가 성공하면 기존 입력을 교체하며, 추출한 본문은 직접 수정한 뒤 **시작**을 눌러 분석할 수 있습니다. 설정 변경이나 재실행으로 편집 내용이 덮어써지지 않습니다. 같은 파일을 다시 가져오려면 업로드를 지우고 다시 선택하세요. 업로드를 지워도 입력창의 본문은 유지됩니다.

파일은 최대 **20MB**, 추출한 본문은 최대 **20,000자**입니다. 암호화·손상 PDF, 텍스트 없는 PDF, 한도를 초과하는 PDF는 오류를 안내하고 기존 입력을 유지합니다. 긴 본문을 임의로 잘라 넣지 않습니다. 스캔 이미지의 OCR은 지원하지 않으며, PDF의 표·다단 편집 등 복잡한 배치는 추출 후 확인이 필요합니다. PDF 추출 자체에는 외부 API를 사용하지 않고 업로드 파일을 별도로 디스크에 저장하지 않습니다. **시작** 이후의 본문 기록과 외부 API 전송은 아래 기존 동작을 따릅니다.

## 로컬 설치 및 실행

macOS / Linux:

```bash
cd /path/to/123
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m streamlit run app.py
```

Windows PowerShell:

```powershell
cd C:\path\to\123
py -3.11 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m streamlit run app.py
```

테스트 도구가 필요하지 않다면 `requirements.txt`만 설치해도 실행할 수 있습니다. 설치된 Streamlit이 표시하는 로컬 주소를 브라우저에서 엽니다. 기본 모드는 **테스트용 Mock**이며 키 없이 전체 UI·승인·반복·다운로드 흐름을 실행할 수 있습니다.

## 실제 API 설정

`.env.example`을 `.env`로 복사하고 본인의 서비스 키를 **로컬 파일 또는 환경변수**에 설정하세요. `.env`는 Git에서 제외합니다. 클라우드에서는 환경 설정의 비밀값 입력 기능을 사용하고 채팅에 키를 보내지 마세요.

| 변수 | 용도 |
| --- | --- |
| `LLM_API_KEY` | OpenAI API 키: 문장 개선 및 의미 검토에 필요 |
| `GPTZERO_API_KEY` | GPTZero API 키: 최초 및 후보 판독에 필요 |
| `LLM_MODEL` | JSON 응답과 `max_completion_tokens`를 지원하는 Chat Completions 모델. 기본 `gpt-4o-mini` |
| `PDF_FONT_PATH` | 선택 사항: 대체 한글 TrueType 글꼴 절대 경로 |
| `TEXTLAB_HOSTED` | 웹 호스팅에서 `1`. 기본 `0` |
| `TEXTLAB_SAVE_HISTORY` | 서버에 원문·이력 JSON 저장 여부: `1`/`0`. 기본 로컬 `1`, 호스팅 `0` |
| `TEXTLAB_MAX_CONCURRENT_RUNS` | 한 서버 프로세스의 동시 작업 수: 1~8, 기본 2 |
| `APP_ACCESS_PASSWORD` | 선택적 사이트 비밀번호. 호스팅의 실제 API 모드에는 필수 |

일반 로컬 환경에서는 `OPENAI_API_KEY`도 대체 입력으로 지원합니다. 이 클라우드의 예약 변수 이름 제한 때문에 저장된 비밀값 요구 사항은 `LLM_API_KEY`를 사용합니다. 기존 주입 환경변수는 `.env`로 덮어쓰지 않습니다.

UI에서 **실제 API**를 선택하고 외부 전송에 동의한 뒤 실행하세요. 키가 없거나 권한·요청·응답 검증에 실패하면 구체적인 설정 오류 또는 안전한 오류 메시지를 표시하며 Mock으로 전환하지 않습니다. 유료 API 이용 권한과 충분한 잔액이 필요합니다. 서비스의 언어·입력 길이·지역·계정 제한과 이용약관을 확인하세요. 제한을 우회하는 기능은 없습니다.

Streamlit Community Cloud에서는 같은 이름을 앱의 Secrets에 최상위 TOML 항목으로 설정할 수 있습니다. 비밀번호가 설정되면 본문에 접근하기 전에 로그인 화면이 표시됩니다. `TEXTLAB_HOSTED=1`인 서버에서 실제 API를 쓰려면 `APP_ACCESS_PASSWORD`가 필요합니다. 공개 체험 사이트는 키와 비밀번호 없이 Mock 모드로 제공할 수 있습니다. 로그인은 공유 사이트 비밀번호 방식이며 사용자별 계정·청구 관리 기능은 아닙니다.

### 판독 점수의 의미

- 실제 판독: [GPTZero 공식 API](https://gptzero.me/docs/api)의 `POST https://api.gptzero.me/v2/predict/text`에 `document`를 전송합니다. `documents[0].completely_generated_prob × 100`만 표시합니다. 이 값은 GPTZero의 문서 전체 AI 생성 분류 추정치이며 AI가 작성한 문장 비율이나 보편적인 저자 확률이 아닙니다. 필드가 없으면 실패 처리하며 다른 점수로 대체하지 않습니다.
- 개선/의미 검토: [OpenAI Chat Completions](https://platform.openai.com/docs/api-reference/chat/create)의 공식 HTTPS API를 사용합니다. 의미 점수는 모델 자체의 판단이며 교정된 확률이나 사실 보증이 아닙니다.
- Mock: 텍스트 해시에서 생성한 재현 가능한 **가상 값**입니다. 문장 개선은 공백·줄바꿈 예시만 수행하고, 의미 검사는 공백 제외 동일성만 확인합니다. 실제 탐지·의미 모델·성능 측정으로 해석하면 안 됩니다. UI와 보고서에 Mock 표시가 포함됩니다.

새 판독기는 `Detector.detect(text) -> Detection`, 새 개선 모델은 `Rewriter.generate(...) -> list[Revision]`와 `assess(original, candidate) -> SemanticAssessment`를 구현하고 `build_providers`에 등록하면 됩니다. 한 실행 안에서 판독 서비스를 바꿀 수 없습니다. 서비스별 서로 다른 점수를 동등한 척도로 비교하지 마세요.

## 의미·사실 보존과 사용자 승인

수치(부호·소수 포함), 따옴표 인용, URL, 대괄호 인용, 대문자 약어, 참고문헌 꼬리 부분과 지정한 보호 용어의 변경을 보수적으로 차단합니다. 모든 고유명사를 규칙만으로 식별할 수 없으므로 중요한 이름·전문 용어는 UI 보호 목록에 한 줄씩 넣으세요. 모델에도 고유명사·전문성·문체·논리 구조를 유지하고 근거 없는 내용을 추가하지 않도록 지시합니다. 자동 검사에는 한계가 있으며 숫자의 문맥·귀속이나 미묘한 의미 변경은 최종 사용자가 확인해야 합니다.

중요 수정은 모델이 표시하거나 설정한 문자 변경 비율을 초과한 후보입니다. 점수·의미 기준을 통과한 후보만 승인 화면에 표시합니다. 거절하면 다음 유효 후보를 검토하고, 모두 거절되면 이전 버전을 유지합니다. 승인으로 보호 검사나 의미 기준을 우회할 수 없습니다. 중지하면 진행 중 비동기 요청을 취소하고 이미 채택한 최저 점수 버전을 유지합니다. 외부 서비스에서 이미 처리된 요청은 취소 후에도 청구될 수 있습니다.

## 사용량, 비용, 오류 처리

기본 한도는 API 요청 200회와 **예약 예상 비용** 5 USD입니다. 생성 1회, 후보별 의미 검토 1회, 의미 기준 통과 후보의 판독 1회가 각각 요청에 포함됩니다. 초기 판독과 재시도도 포함합니다. 최대 20회·후보 3개는 정상 경로에서 초기 1 + 20 × (생성 1 + 의미 3 + 판독 3) = 141요청입니다. Mock은 실제 호출량과 비용을 소비하지 않습니다.

요청 직전에 UI에 입력한 보수적인 요청당 금액을 예약합니다. 기본 추정액은 판독 0.01 USD, LLM 0.02 USD이며 **현재 서비스 가격표가 아닙니다**. 계정 요금·입력 길이·토큰 상한에 맞춰 설정하세요. 토큰 사용량은 응답에 제공된 실제 집계를 별도로 기록합니다. 예약액은 실제 청구액을 강제 제한하지 못하므로 공급자 계정의 지출 한도도 설정하세요. 한도 도달 시 새 요청을 중단하고 이전 최선 결과를 반환합니다.

HTTP 429·5xx 및 일시적인 연결 오류만 최대 3회 시도합니다. 지수 지연과 제한된 `Retry-After`를 사용합니다. 인증 오류·잘못된 JSON·범위 밖 점수·잘린 모델 응답은 성공으로 취급하지 않습니다. TLS·서명 검증을 비활성화하지 않으며 환경 프록시와 CA 설정을 유지합니다. 화면·이력에는 키나 외부 오류 응답 본문을 저장하지 않습니다.

## 기록과 다운로드

로컬 기본 설정에서는 현재 작업 디렉터리의 `.runs/<실행 ID>.json`에 원문·설정·모든 후보·점수·검증·채택/거절·중지 이유를 자동 저장합니다. 각 업데이트는 원자적으로 교체됩니다. **입력 전문이 들어 있는 평문 로컬 파일**이므로 필요가 없어지면 `.runs/`를 삭제하세요. 호스팅 기본 설정(`TEXTLAB_HOSTED=1`, `TEXTLAB_SAVE_HISTORY=0`)은 서버 파일 저장을 끄고 세션 내 결과와 다운로드로 이력을 제공합니다. 기존 기록을 자동 삭제하지는 않습니다. 명시적으로 `TEXTLAB_SAVE_HISTORY=1`을 설정하면 호스팅에서도 파일 저장을 켤 수 있습니다. 외부 API 모드에서는 원문과 후보가 해당 서비스에도 전송됩니다. 브라우저를 닫아도 이미 시작된 작업은 프로세스가 살아 있는 동안 진행될 수 있으므로 끝내려면 중지를 누르세요. 서버 재시작 시 실행 중 작업과 승인 대기는 복원하지 않습니다.

완료 또는 중지 후 PDF·DOCX와 전체 JSON 이력을 내려받습니다. PDF에는 저장소에 포함된 NanumGothic 글꼴을 임베드해 한글을 표시합니다. 글꼴의 OFL 라이선스와 출처는 `textlab/assets/`에 있습니다. DOCX는 편집 가능한 문서로, 원문과 모든 후보를 포함합니다. 운영체제에 NanumGothic이 없으면 워드 프로그램이 사용 가능한 한글 글꼴로 대체할 수 있습니다.

## 검증

```bash
python -m pytest -q
python -m pip check
```
